# 手机壳发布页字段清单

**先说清楚这份文档的状态**：手机壳类目的字段**没有实测过**。它与女装（`catId=1623`）共用同一套发布页
框架，页面机制部分可以沿用，但**属性项、SKU 轴、图片要求必须自己跑一次 probe 确认**。
这份文件的价值在于：告诉你哪些地方一定会踩坑、哪些规则是平台明文写死的。

实测优先于本文档。字段以最近一次 `probe-publish-page.js` 输出为准。

## 一、类目与 catId

发布页必须带 `catId`，否则只显示"宝贝发布异常"：

```text
https://item.upload.taobao.com/sell/v2/publish.htm?catId={类目ID}&fromAICategory=true
```

拿手机壳 catId 的办法：打开不带参数的 `item.upload.taobao.com/router/publish.htm`，用"搜索发品"
输入"手机壳"，选中类目后落地页地址里就带上了 `catId`。把结果填进 `item.json` 和 `selectors.json`。

## 二、标题（这里有平台明文红线）

手机壳属于"**可以出现品牌词，但必须带适用词**"的叶子类目。淘宝《3C数码配件发布规范》原文要求：
标题、导购标题、图片等信息里的品牌词都要加"适用于"字样，**字体大小不得小于 50%**，
不规范发布会被下架、删除、扣分（[官方公告](https://qn.taobao.com/headline/news/10701499/)）。

具体到脚本：

- `title-guard.js` 会拦住"iPhone 15 手机壳"这类裸品牌写法，只放行"**适用于**iPhone 15 手机壳"。
- 预检不通过时脚本**不会打开页面**，并打印修正建议，避免批量生产违规标题。
- 图片里的品牌词脚本看不见，**属于人工检查项**，发布前逐张看一眼。

| 字段 | 说明 |
|---|---|
| 宝贝标题 | 长度上限以 probe 实测为准（女装类目是 60 字符）。`selectors.json` 的 `limits.titleChars` 控制校验 |
| 导购标题 | 女装类目实测填了会报错，手机壳类目是否可用待实测；不用就别配规则 |

## 三、商品属性

属性行容器 ID 形如 `#sell-field-p-<属性ID>`，属性名在该行标签的 `title` 上。
**用容器 ID 定位比用文案定位稳**，页面文案会变。

填写顺序建议：

1. 跑 probe，导出控件清单；
2. 把必填属性挨个填进 `selectors.json` 的 `rules`，键名与 `item.json` 的 `attributes` 对应；
3. 拿不准的写 `"strategy": "manual"`，先跑通流程，再逐条换成实测选择器。

属性下拉是**虚拟滚动列表 + 搜索框**：点开 → 在搜索框里输入目标词 → 点选项。`choose` 策略已内置这个流程。
**取值必须是平台原词**，找不到就留空并报告，不要填近义词——词义混淆（比如把"A字裙"填进"版型"）
是属性填错最常见的原因。

## 四、SKU

手机壳的核心工作量，单独一份文档：见 [sku-table.md](sku-table.md)。

要点：轴值通常是"适用机型 + 颜色/图案"，机型这种长尾值需要"自定义新增"，行数=轴值数量的乘积。
脚本按行文本匹配轴值填价格/库存/编码，不依赖列顺序。

## 五、图片

| 区域 | 说明 |
|---|---|
| 主图 | 数量与尺寸要求以 probe 实测为准。女装类目 2026-09 实测为 1:1 推荐 1440×1440 以上、3:4 推荐 1440×1920 以上，**旧的 800×800 资料已过期**；手机壳是否同样要求待实测 |
| 主图内文字 | 出现品牌词必须带"适用于"且字号不小于 50%（平台明文），**脚本无法校验图片文字** |
| 颜色选项图 | 按颜色值给图；`item.json` 的 `optionImages` 配置 |
| 详情图 | 高/宽比不要超过页面限制，否则会被裁剪 |
| 白底图/长图 | 选填，按类目提示 |

**重复铺货提醒**：多个链接共用同一套主图和详情页，会被平台的图片识别判定为重复铺货而降权。
200–300 个链接的规模下，这是最容易被忽略的坑——每个链接至少要有一张能区分彼此的主图。

## 六、物流与上架时间

- 运费模板：必须写**店铺里已存在的模板名**，否则选不中；
- 发货时间：24/48/大于 48 小时；
- 上架时间：立刻上架 / 定时上架 / 放入仓库。

**批量上新的建议默认值是"放入仓库"。** 先把商品建好、人工过一遍，再批量上架；
这样"机器人出错"和"错误链接对外可见"之间就隔了一道闸。

## 七、提交前检查清单

1. 标题计数器已更新，没超上限，品牌词都带"适用于"；
2. 必填属性都有值，没有红色提示；
3. SKU 行数 = 轴值数量乘积，价格库存无空格、无 0；
4. 主图至少一张，顺序正确，图内品牌词合规；
5. 运费模板、发货时间、上架时间已选；
6. 页面"错误(N)"已归零；
7. 这条链接和已有的链接**不是同款重复铺货**。
