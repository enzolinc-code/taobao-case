# 排查顺序

字段填不进去时按这个顺序查，不要跳步。

| 症状 | 先查这个 |
|---|---|
| 连不上 CDP | Chrome 是否带 `--remote-debugging-port=9222` 在跑；看 `check-env.js` 打印的启动命令 |
| 页面跳登录页 | 登录态过期，真人在那个窗口重新扫码 |
| 找不到元素 | 页面改版或选择器过期 → 重跑 `probe-publish-page.js` |
| 元素找到但填了没反应 | 换 strategy：`type` 与 `native` 互换试 |
| 上传图片没反应 | 控件是否在 iframe 里；文件路径是否存在；主图尺寸是否符合页面要求 |
| 出现滑块/短信/人脸 | **停**，交真人，不要重试 |
| 报"操作过于频繁" | 停当天的批量任务 |
| 预检直接拦截 | 看报告里的 `[预检拦截]`：标题品牌词没带"适用于"，或 SKU 重复/价格库存非法 |

## SKU 表专项

| 症状 | 原因 | 处理 |
|---|---|---|
| `SKU：轴「XX」：找不到选项` | 该轴是"自定义新增"型，不是下拉型 | 把该轴 strategy 改成 `addValue`，selector 指向输入框 |
| `表格里找不到轴值匹配的行` | 轴值没加进表格；或 item.json 写的字和表格显示的不完全一样 | 先在页面上手动加一个值，看看表格里显示成什么字，用它改 item.json |
| 成功行数少于预期 | 轴值有重复（平台会合并），或某个值被平台拒绝 | 看预检的"SKU 重复"提示；重复值脚本会直接拦下 |
| 行数对但价格没落上 | 表格列用了直接赋值 | 该列 strategy 换成 `native` |
| 页面很卡、填一半超时 | 单链接 SKU 行数太多 | 拉长 `TAOBAO_PACE_MIN_MS`/`TAOBAO_PACE_MAX_MS`，或把链接拆小 |

## 批量专项

| 症状 | 处理 |
|---|---|
| 提示"今日预算已用完" | 这是设计如此。要超预算加 `--ignore-budget`，先想清楚风控代价 |
| 商品被跳过 | 账本里已有 `ok` 记录。要重跑加 `--force` |
| 整批停在某个商品 | 那个商品触发了 `blocked` 或 `login-required`，看账本里该条的 `reason` 和 `riskSignals` |
| 想从失败处接着跑 | 直接重跑同一条命令：账本会自动跳过已完成的商品 |

## 页面改版之后

1. 重跑 `probe-publish-page.js --cat-id <类目ID>`，导出新的控件清单和 `page.skuArea`；
2. 用 `record-flow.js` 录一遍真人操作（在接管的 Chrome 里正常操作，结束时在输出目录放一个 `STOP` 文件）；
3. 按新的实测结果改 `selectors.json`——**只改配置，不改脚本**；
4. 先在 1 个商品上跑通，再开批量。
